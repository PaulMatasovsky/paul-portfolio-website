## How Each Audit Is Organized

Each audit gets its own dated folder, following the [toolkit conventions](https://github.com/PaulMatasovsky/qa-toolkit#conventions):

```text
2026-11-website-2.5-regression/
├── Test-Plan.md
├── Website-Regression-Test.md
├── Test-Execution-Log.md
├── Test-Summary-Report.md
├── bugs/
│   └── BUG-001.md
└── evidence/
    └── BUG-001-short-description.png
```

A check is only marked **Pass** after I've run it. Screenshots are cropped or blurred to remove private details before they're committed.
