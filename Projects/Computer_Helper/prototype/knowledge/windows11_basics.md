# Windows 11 — Example Local Help Notes

**Project classification: AI-led** · **Example reference only; check against current Microsoft guidance before deployment.**

## Open File Explorer

Press the Windows key and E together to open File Explorer. The left navigation pane may show common folders such as Downloads, Documents, and Pictures.

## Find downloaded files

Open File Explorer and choose Downloads. In Microsoft Edge or Google Chrome, Ctrl+J opens the browser's downloads list. Some browsers or websites may use another save location.

## Open Windows Settings

Press the Windows key and I together to open the Settings application.

## Change text size

Open Settings, choose Accessibility, and find Text size. Increase it and apply the change. Changing text size is different from changing the scale of the entire screen.

## Safety reminder
