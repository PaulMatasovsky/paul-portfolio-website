# AI Collaboration and Authorship

**Status:** Draft disclosure, 2026-10-26.

## Provenance of this initial documentation

The idea originated from a family support problem and the project owner's discussions of the users' needs. The owner chose the essential requirements: one low-complexity assistant, no additional recurring AI fees, limited **local** navigation only, **read-only guidance** on websites, password manager separation, and planned Windows/macOS support.

AI generated the initial project documentation, synthesized the requirements, proposed a technical architecture and test scenarios, and created the initial GitHub folder structure. These materials require owner review and are **not independently authored technical specifications or verified implementation**.

## Portfolio claims: use and avoid

**Accurate now:** “Identified requirements and safety boundaries for a planned cross-platform computer-assistance tool; used AI to draft architecture, security and test documentation.”

**Not accurate yet:** “Built a working AI assistant,” “deployed it to two users,” “verified safe browser guidance,” or “reduced support requests.”

Any future claim about code authored, functionality, test performance or usability should be updated from actual work records, not inferred from a roadmap.

## ADR authorship

The portfolio repository's [ADR-000](../../Documentation/ADRs/ADR-000.md) says final accepted ADR prose is written personally by the project owner. The AI-produced material in the [ADRs folder](ADRs/README.md) is therefore **decision preparation only**, not an accepted ADR. The owner should write final ADRs after research and selection.
