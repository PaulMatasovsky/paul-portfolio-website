## Working project title

Computer Helper — Privacy-Conscious Assistance for Windows and macOS

## Short description

An early-stage, family-inspired project to design a simple computer assistant for people who need guidance navigating everyday desktop applications and websites. The design focuses on one clear interface, one-step instructions, local-only approved navigation, read-only website guidance, and independent password management.

## Problem / approach / evidence

**Problem:** Remembering passwords is only part of the difficulty; unfamiliar operating systems, documents and websites can be confusing even when accounts are accessible.

**Proposed approach:** Local AI where hardware permits, a cross-platform user interface with Windows/macOS adapters, explicitly consented screen understanding, and a code-enforced boundary between limited local actions and guidance-only website support.

**Evidence available today:** Requirements, candidate architecture, security boundaries, roadmap and test plan—AI-drafted from the owner's requirements.

**Evidence not yet available:** Executable application, tests, user observations, hardware benchmarks or deployment.
