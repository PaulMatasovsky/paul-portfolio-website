# Architecture Decision Preparation

**No accepted Computer Helper ADRs yet.** In keeping with the [portfolio ADR process](../../../Documentation/ADRs/ADR-000.md), the owner writes final decision records after evaluating real alternatives.

| Proposed ADR | Question to resolve |
| --- | --- |
| 000 — Local control boundary | Which approved folder/app actions are necessary? What tests prove the allowlist holds? |
| 001 — Cross-platform architecture | Which shared UI and separate Windows/macOS APIs will meet the requirements? |
| 002 — Local inference | Which model runs acceptably on each computer without a recurring fee? |
| 003 — Screen and browser interpretation | Screenshots, accessibility metadata, or both? How are sensitive screens protected? |
| 004 — Credential separation | How will independent password managers and recovery work without AI access? |

These are **AI-drafted research prompts**, not selected technologies or tested decisions. See [Architecture](../Architecture.md) for candidates and [Security and Privacy](../Security_and_Privacy.md) for the existing requirements.
